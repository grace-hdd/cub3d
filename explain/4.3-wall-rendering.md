# Task 4.3 - Flat-colored wall rendering

Files: `src/render/walls.c`, `src/render/events.c`.

## One wall slice per screen column

`draw_walls` loops over all screen columns. For each column it calls
`cast_ray`, which fills a `t_ray` with the wall hit and its perpendicular
distance. The perpendicular distance is used instead of the raw ray length so
the wall remains straight across the screen without a fisheye effect.

## Wall height

For a wall one map cell deep, the projected height is:

```text
line_height = WIN_H / perp_dist
```

The slice is centered vertically around the horizon:

```text
draw_start = WIN_H / 2 - line_height / 2
draw_end   = WIN_H / 2 + line_height / 2
```

Both endpoints are clamped to the image boundaries before drawing. This
prevents a nearby wall from writing outside the image buffer.

## Drawing order

`run_game` first draws the ceiling and floor, then draws each wall slice in
flat gray, and finally sends the completed image to the window. Textures are
intentionally not used yet; selecting and sampling the four XPM textures is
part of Phase 5.
