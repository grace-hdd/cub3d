# Task 1.3 – Parse `NO SO WE EA`

File: `src/parsing/parse_texture.c`.

## `parse_texture(line, game)`
Handles one line. Returns `0` = texture stored, `1` = error (message already printed), `-1` = this is not a texture line (the caller tries something else).

Steps:
1. `get_index` compares the first 2 characters with `NO`, `SO`, `WE`, `EA` and returns the index (`NO`..`EA`), or `-1`.
2. The identifier must be followed by a space/tab (or the end of the line). So `NOX a.xpm` is not a texture line.
3. If `cfg.tex[i]` is already set, it is a **duplicate** → error.
4. Skip the spaces after the identifier, ignore the spaces at the end, and take the rest with `ft_substr`. Extra spaces anywhere around the path are fine.
5. Empty path → `missing texture path`. A path that still contains a space or tab (two words) → error.
6. `check_path`: the path must be longer than 4 chars and end with `.xpm`, and `open` must succeed. The fd is closed right away (MiniLibX opens the file itself later).

The path is stored in `game->cfg.tex[i]` and freed by `free_game`. If a check fails after the store, the string is still freed by `free_game`, so nothing leaks.

Any order works, because each line is handled alone and the index tells where to store it.

## `parse_textures(game)` – temporary driver
Loops over `game->lines`, calls `parse_texture` on each, and rejects **unknown identifiers**: a non-empty line whose first character is not one of `F C 0 1`, space or tab (`XX a.xpm` → `unknown identifier in the map file`). It ignores `F`/`C` lines (task 1.4) and map lines (1.6). Task 1.5 will replace it with the real loop that finds where the map starts and requires all 6 elements.

It is called from `main` right after `read_file`.
