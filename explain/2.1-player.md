# Task 2.1 - Find the player

File: `src/parsing/parse_player.c`.

Task 2.1 runs after the map has been copied into the rectangular
`game->map.grid` by task 1.6.

## Scanning the grid

`scan_players` visits every cell in row-major order. `is_spawn` recognizes
the four valid player markers:

```text
N  S  E  W
```

When a marker is found, `set_player` stores its column in `player.x`, its row
in `player.y`, and its marker in `player.spawn`. The coordinates are grid
coordinates; converting them to world coordinates and setting direction
vectors belongs to the later raycasting setup.

The scan continues after finding a player so that duplicate players are
detected instead of silently accepting the first one.

## Validation

`parse_player` rejects a map with no player and a map with more than one
player. A valid map has exactly one marker, and the function returns success.
Errors go through `print_error`; `main` then calls `free_game` on the failure
path.
