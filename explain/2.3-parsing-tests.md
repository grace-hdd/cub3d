# Task 2.3 – Parsing test maps and script

Files: `tests/run_parsing.sh`, `tests/maps/valid/`, `tests/maps/invalid/`, `tests/textures/t.xpm`.

## Layout
- `tests/textures/t.xpm`: a tiny real `.xpm` file. The parser only checks that the path ends in `.xpm` and can be opened, so every test map points to it (`tests/textures/t.xpm`, relative to the repo root).
- `tests/maps/valid/*.cub`: must be accepted. `basic`, `spaces_around`, `spaces_inside`, `short_rows`, `trailing_blank_lines`, `crlf`.
- `tests/maps/invalid/*.cub`: must be rejected, each for one reason:
  - 2.1: `no_player`, `two_players`.
  - 2.2: `hole_in_wall`, `zero_next_to_space`, `zero_on_border`, `player_on_border`, `short_row_open`, `hole_top`.
  - 1.x: `bad_char`, `blank_in_map`, `element_after_map`, `missing_ceiling`, `missing_texture`, `color_out_of_range`.
- The older stubs in `tests/maps/` (`empty.cub`, `sample.cub`, `valid_min.cub`) are not used by the script.

## `tests/run_parsing.sh`
Run from anywhere. It builds libft and MLX, compiles the parser with `-fsanitize=address,undefined` into a temporary binary (removed on exit), and runs every map:
- valid: exit code `0` and nothing printed;
- invalid: exit code `1`, the first stderr line is `Error`, and no sanitizer report (so a leak or memory error fails the test too).
It prints `passed: N  failed: M` and exits non-zero if anything failed.

## Result
20 maps, 20 passed. Each invalid map was also checked by hand to fail with the intended message, not a side error.
