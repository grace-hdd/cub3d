# Task 1.5 – Find the map start, require all 6 elements

File: `src/parsing/parse_elements.c`. It replaces the temporary driver `parse_textures` (removed from `parse_texture.c`). `main` now calls `parse_elements`.

## `parse_elements(game)`
Walks `game->lines` from the top:
1. `parse_element` = `parse_texture`, and if that returns `-1`, `parse_color`. `1` → error (message already printed), `0` → element stored, `-1` → not an element.
2. A blank line (only spaces/tabs) is skipped.
3. The first non-blank line that is not an element is the **map start**. It must begin with `1`, `0`, space or tab (`is_map_line`), otherwise → `unknown identifier in the map file`. The loop stops there.
4. End of file reached without a map → `no map found in the file`.
5. `all_elements`: the 4 textures are set and `floor` / `ceiling` are not `-1`. If not → `missing element before the map` (this also rejects a map placed first).
6. The index is saved in `game->map_start` (new field in `t_game`); task 1.6 copies the grid from there.
7. `check_after_map` scans the lines after the map start: any line beginning with `NO SO WE EA F C` followed by a space/end of line → `an element cannot come after the map`. Other bad lines (wrong characters, empty lines inside the map) are task 1.6's job.

Elements may come in any order and be separated by blank lines.
