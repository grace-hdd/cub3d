# Task 6.1 - Input state and frame loop

Files: `src/render/input.c`, `src/render/events.c`.

## Key state

Key press and release events update `game->input` rather than performing
movement directly in an event callback. The state remains set while a key is
held and is cleared when the key is released. The stored keys are W/A/S/D and
the left/right arrows; their actions are implemented by later Phase 6 tasks.

ESC still closes the game immediately. The window close event uses the same
cleanup path.

## Per-frame rendering

`mlx_loop_hook` calls `render_frame` on every iteration of the MiniLibX event
loop. It redraws the background and wall slices into the image buffer, then
displays the completed image. Later movement and rotation code can update the
player state between frames without changing the event wiring.
