# Task 1.7 - Parsing cleanup

Task 1.7 completes the review fixes for the configuration parser.

## Whitespace

`is_space` accepts spaces, tabs, carriage returns, vertical tabs and form
feeds. This allows element and color lines from CRLF files to be parsed
without treating the trailing carriage return as data. Map validation still
accepts only ordinary spaces inside the grid.

## Color parsing

The RGB parser uses `parse_comma` instead of incrementing the input pointer
inside a condition. This makes the separator check explicit and keeps the
pointer movement easy to verify.

## Element checks

Texture identifiers are selected by `texture_id`, avoiding a compound literal
inside `is_element_line`. Generic blank-line handling is kept in
`parse_utils.c`.

## Later fixes (done with task 2.2)
`read_file.c` `strip_newline` also removes a trailing `\r`, so CRLF map rows
are valid too. The regression script `tests/run_parsing.sh` came with task 2.3.
