# Task 0.1 – Repo skeleton

## Files
```
inc/cub3d.h        the only header
src/main.c         program entry point
Makefile           builds libft, MiniLibX and cub3D
.gitignore         objects, libft.a, MLX build files, the binary
tests/maps/        test maps
```

## The Makefile in short
- `-Iinc -Ilibft -Iminilibx-linux` tells the compiler where to find `cub3d.h`, `libft.h` and `mlx.h`.
- `libft.a` and `libmlx.a` are built by calling `make -C` on their folders. MiniLibX is built with `CC="cc -std=gnu17"` because its old code does not compile with the newest gcc default (C23).
- `-lXext -lX11 -lm` link the X11 libraries MiniLibX needs and the math library.
- Object files go to `obj/`, mirroring the `src/` folders (`$(dir $@)` + `mkdir -p`).
- Each `.o` depends on `inc/cub3d.h`, so changing the header recompiles everything.
- Running `make` twice does not relink.
- Flags: `-Wall -Wextra -Werror`.

if (check_args(argc, argv))        return (1);               // 1.1

Later phases add parsing, the window and the game loop between `init_game` and `free_game`. Every error path must end with `free_game`.
