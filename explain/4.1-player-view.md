# Task 4.1 - Set the player view

File: `src/render/player_view.c`.

## World position

The parser stores the player's map cell as integer grid coordinates. The
rendering code adds `0.5` to both coordinates so the player is placed at the
center of that cell instead of its top-left corner. For example, grid
position `(3, 2)` becomes world position `(3.5, 2.5)`.

## Direction

The map uses rows that increase downward, so north points toward negative `y`.
The four spawn markers become unit direction vectors:

```text
N = ( 0, -1)
S = ( 0,  1)
E = ( 1,  0)
W = (-1,  0)
```

## Camera plane

The camera plane is perpendicular to the direction vector. Its length controls
the field of view. A length of `0.66` is a common cub3D choice that gives a
roughly 66-degree field of view. Increasing it widens the view; decreasing it
narrows the view. The same length must be used consistently for both
components.
