# Task 1.6 - Copy the map into a rectangular grid

File: `src/parsing/parse_map.c`.

## `parse_map(game)`

Task 1.5 stores the first map row in `game->map_start`. Task 1.6 validates
every line from that index to the end of the file, then copies those lines
into `game->map.grid`.

The map height is the number of lines after `map_start`:

```c
game->map.height = game->nb_lines - game->map_start;
```

The width is the length of the longest row. Every row in the allocated grid
has this same width, so shorter rows can be safely accessed later by the
raycaster.

## Validation

`valid_char` accepts only:

- `0` and `1` for floor and walls
- `N`, `S`, `E`, and `W` for the player spawn
- ordinary spaces

`valid_line` rejects empty lines and any other character. Player-count and
map-closure checks are separate tasks handled later.

## Padding

`copy_row` copies the original row into the rectangular grid. If the source
row ends before the maximum width, the remaining cells are filled with
spaces. Each copied row receives a final `'\0'`, making it a normal
null-terminated string.

Allocation failures return an error. `main` then calls `free_game`, which
frees any rows allocated before the failure.
