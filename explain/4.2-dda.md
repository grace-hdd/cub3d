# Task 4.2 – DDA raycasting

File: `src/render/raycast.c`. Public function: `cast_ray(game, x, ray)`. New struct `t_ray` in `cub3d.h`.

## One ray per screen column
`init_ray` turns the column `x` (0..`WIN_W`-1) into `camera_x = 2 * x / WIN_W - 1` (from -1 at the left edge to about +1 at the right edge) and builds the ray direction `dir + plane * camera_x` (the vectors set in 4.1). Because the plane is perpendicular to `dir`, the center column goes straight ahead and the edges fan out over about 66 degrees.

## DDA setup (`t_ray`)
- `map_x`, `map_y`: the grid cell the ray is in (starts at the player's cell).
- `delta_x`, `delta_y`: how far the ray travels to cross one whole cell in x (or y): `|1 / dir_x|`, `|1 / dir_y|`. If a component is exactly 0 the ray never crosses those lines, so the delta is `1e30` (avoids dividing by zero and is never chosen).
- `step_x`, `step_y`: `-1` or `+1` depending on the sign of the direction.
- `side_x`, `side_y`: the ray length to the first vertical / horizontal grid line (`init_step_x`, `init_step_y`: the fraction of the cell left in that direction times `delta`).

## The loop (`cast_ray`)
Repeat: advance along the axis whose next grid line is closer (`side_x < side_y` → move in x, `side = 0`; otherwise move in y, `side = 1`), add that axis's `delta` to its `side_*`, and move `map_*` by `step_*`. Stop when `is_wall` says the new cell blocks the ray. `side` tells which kind of face was hit (`0` = a vertical face, hit going in x, so a west or east face; `1` = a horizontal face, north or south).

`is_wall`: `1`, a space, or any cell outside the grid. The spawn letter (`N S E W`) and `0` are open. The outside-grid test cannot trigger on a map that passed 2.2; it only prevents a crash.

## Perpendicular distance
`perp_dist = side_x - delta_x` (or the y version): the ray length at the last step back to the wall face, measured along the camera direction, not along the ray. Using the real ray length would give the fisheye effect (walls bending at the screen edges). Task 4.3 turns `perp_dist` into a wall height; task 5.3 uses `perp_dist`, `side` and the ray direction to find where on the wall the ray landed (`wall_x`).

## Tested (hard-coded 7x7 room, no parser, no display needed; ASan + UBSan clean)
`tests/test_dda.c` prints each result:
- N, S, E, W center rays from the room center: distance 2.5, hit cell (3,0), (3,6), (6,3), (0,3), correct `side`.
- left edge column next to the west wall: `0.5 / 0.66 = 0.757576`, side 0; right edge column: 2.5, side 1.
- all 1280 columns facing a flat wall give the same 2.5 (proves there is no fisheye).
